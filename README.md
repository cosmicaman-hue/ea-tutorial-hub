## 🚨 Troubleshooting

### Issue: Can't open the system
**Solution:** 
- Check URL: http://127.0.0.1:5000/scoreboard/offline
- Verify server is running (Flask should be active)
- Try: http://localhost:5000/scoreboard/offline

### Issue: Data not saving
**Solution:**
- Check browser allows localStorage
- Try incognito mode
- Check browser storage not full
- Restart browser

### Issue: Excel import not working
**Solution:**
- Verify file is .xlsx format
- Close Excel before importing
- Check file not corrupted
- Try export first as test

### Issue: Scores not showing
**Solution:**
- Check month is selected
- Verify student exists in Students tab
- Try refreshing page
- Check date format (YYYY-MM-DD)
